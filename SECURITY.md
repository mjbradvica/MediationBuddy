# Security Policy

## Supported Versions

The current versions are supported; MediationBuddy follows Microsoft's policy.

| Version | Dotnet | Supported          |
| ------- | ------ | ------------------ |
| >0.7.0  | 8/9/10 | :white_check_mark: |

## Reporting a Vulnerability

MediationBuddy will be normally updated on each dotnet major update.

The exception being if a sub-package has a vulnerability.

Please create an Issue to make a report.
